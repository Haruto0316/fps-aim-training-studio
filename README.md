# FPS Aim Training Studio

Windows 向けの Godot 4 / GDScript 製 3D エイムトレーナーです。固定視点でのクリック、移動中の射撃、遮蔽物を使った追従などをオフラインで練習できます。

## 起動と操作

1. Windows 版 Godot 4.7.2 Standard のプロジェクトマネージャーで、作業フォルダーの `project.godot` をインポートします。
2. プロジェクトを開いて **F5** で実行します。
3. ホームで練習を選び、「この条件で開始」を押します。「標準練習モード」には固定視点の5種類があります。「移動練習」は移動可能で既定45秒、「移動ダミー撃破」は移動可能で既定60秒です。開始前にループするプレビューでモードの動きを確認し、ダミーの大きさ（半径0.08〜0.65 m）を調整できます。変更した練習条件はモードごとに、アプリを開いている間保持されます。
4. マウスで視点を動かし、左クリックで射撃します。Esc で一時停止・再開します。ポーズ画面の「設定」でマウス感度を調整でき、保存後は同じラウンドを再開できます。ウィンドウからフォーカスが外れた場合も一時停止します。
5. 練習終了後に、スコア、命中率、平均反応時間、射撃・命中・ミス回数を確認できます。リトライは同じ条件で新しいラウンドを開始します。

Godot の実行ファイルに `--path .` を渡して起動することもできます。

すべての練習で弾数は無制限です。

## アカウント

ホーム右上の「アカウント」から「新規登録」を選びます。ユーザー名と12文字以上のパスワードを入力し、「登録してログイン」を押してください。同じPCでは、再起動後も登録したユーザー名とパスワードでログインできます。

ログイン中のマウス感度、移動設定、自己ベスト、カスタム練習は `user://accounts/` のアカウントごとのフォルダーに保存されます。「ログアウト」でゲストに戻ると、登録前のデータを使えます。ログインとデータ保存は端末内で完結します。

## 標準練習モード

| モード | 内容 |
| --- | --- |
| Static Clicking | 1体ずつランダムに現れる静止ダミーをクリックします。 |
| Multi Target | 静止ダミーを2〜8体同時に表示します。命中したダミーは別の位置に補充されます。 |
| Smooth Tracking | 「左右」「上下」「円運動」からパターンを選び、一定の周期で動くダミーを追います。 |
| Reactive Tracking | 方向と速度が不規則に変わるダミーを追います。 |
| Target Switching | 2〜8体のうち、▼が付いたダミーだけが命中対象です。正解すると目印が別のダミーに移ります。 |

複数ダミーのモードでは、ラウンドごとに配置パターンを選び、出現範囲内で各ダミーの左右・上下の位置をランダムに決めます。出現範囲の最小値は、大きさと同時出現数に合わせて調整します。Multi Target では命中したダミーだけを新しい位置に補充します。追従モードでは速度と移動範囲を設定でき、追従精度は射撃していない間も記録されます。Target Switching の平均切替時間は、最初の正解を除き、目印が切り替わってから次の正解までを測ります。

## 3D エディター

ホームの「3D エディター」を開くと、床、静止ターゲット、箱を配置した下書きが表示されます。左側のメニューから、静止・移動ターゲット、敵 AI、壁、箱、柱、床、足場、段差、プレイヤー開始位置、ターゲット出現エリア、ルート通過点を追加できます。

| 操作 | 入力 |
| --- | --- |
| 選択 | 3D ビューのオブジェクトを左クリック、または左側の一覧から選択 |
| 移動 | 左ドラッグ。XZ は水平移動、X・Y・Z はその軸だけを移動。スナップ有効時は0.5 m単位 |
| 視点操作 | 右ドラッグで回転、中ドラッグで平行移動、ホイールでズーム、F で選択に寄る |
| 数値編集 | 右側のパネルで XYZ の位置・回転・サイズを入力。Enter で確定 |
| 複製・削除 | 上部ボタン、Ctrl+D、Delete |
| 元に戻す・やり直す | 上部ボタン、Ctrl+Z、Ctrl+Y または Ctrl+Shift+Z。Esc で進行中のドラッグを取り消す |

ターゲットと敵 AI では、形状、色、耐久値、行動パターン、速度、移動範囲、出現と再出現の条件を設定できます。「マップ設定」では、背景色、照明、練習範囲の幅と奥行を調整できます。下書きと操作履歴は、ホームに戻ってもアプリを開いている間は保持されます。

### 移動ルート

1. 左側で「ルート通過点」を追加し、3D ビューで位置を調整します。
2. ターゲットを選び、右側の「移動ルート」で通過点を走らせたい順に登録します。↑・↓で順番を変え、「外す」でルートから除きます。
3. 直線か曲線、往復かループを選びます。「移動プレビュー」で、設定した速度と軌道を確認できます。

通過点が2つ以上あるルートでは、ターゲットは最初の通過点から移動します。ルートがないターゲットは配置位置、または右側で指定した出現エリアから出現します。ターゲットは設定した軌道をたどるため、障害物を避ける経路はエディターで配置してください。

### カスタムシナリオの保存と練習

- 「練習設定」で名前、説明、時間、プレイヤー移動、射撃方式、武器とスコアの数値を設定できます。
- 「保存」で `user://scenarios/` に JSON を保存します。再起動後は、ホームの「カスタム練習」で、配置とターゲットのルートをプレビューし、プレイ・編集・複製・削除できます。エディターの「読み込み」から保存済みシナリオを開くこともできます。
- 「インポート」「エクスポート」で JSON を共有できます。インポートした下書きには新しい ID が付与され、「保存」で自分の一覧に登録できます。未対応の形式や不正な参照を含むファイルは読み込み時に拒否します。
- 「テストプレイ」で編集内容のコピーを練習します。ラウンド終了、または Esc メニューの「エディターへ戻る」で、編集時の下書き・カメラ・選択に戻れます。テストの成績は自己ベストに反映されません。

プレイヤー開始位置を複数置いた場合は、一覧の最初のマーカーを使用します。マーカーの Y 軸回転が開始時の向きです。移動型のカスタム練習では、練習範囲の外周に移動の境界が適用され、床から落ちると開始位置に戻ります。

## 移動ダミー撃破

- 左クリックで射撃します。フルオートは押している間連射し、ターゲットの再出現待ちには射撃を止めます。単発は押すたびに1発撃ちます。どちらも設定された射撃間隔が適用されます。
- 右クリックを押している間は ADS です。既定の1.5倍ズームと感度倍率0.75が適用されます。ズーム時の垂直 FOV は `2 × atan(tan(元の垂直 FOV ÷ 2) ÷ ズーム倍率)` です。
- フルオートでは、左クリックを押し続けている間、ダミーが再出現すると連射が再開します。ポーズ中は再出現までの時間も止まります。
- 照準の色が一瞬変わると射撃、照準の斜線が光ると命中です。画面上部にダミーの耐久値と弾数無制限の表示を表示します。耐久値は既定125で、1発25ダメージです。撃破したダミーは0.65秒後に全回復して再出現します。

モード選択画面で射撃方式と反動を選べます。反動は「なし」「小（従来の強さ）」「中（小の1.5倍）」「大（小の2倍）」の4段階です。倍率は縦・横の両方に適用され、ADS 中は各段階に ADS 用の軽減倍率が掛かります。既定はフルオート、反動・拡散なしです。ダメージ、発射間隔を決める連射速度、ADS、拡散、反動パターン、ダミーの耐久値・移動速度・加速度・再出現時間は `resources/scenarios/strafe_elimination.json` に定義しています。

## 移動型ドリル

ホームの「移動型ドリル」から4種類を選べます。各ドリルの練習条件でダミーの速度、移動範囲、サイズ、時間、射撃方式、反動を設定できます。

| ドリル | 内容 |
| --- | --- |
| Strafe Tracking | 左右に動くダミーを、自分も移動しながら追い続けます。 |
| Cover Tracking | 壁や箱のある射場で、ダミーの一部が見える位置やタイミングを探して追従します。遮蔽物に当たった射撃はミスになります。 |
| Movement Tracking | ジャンプと不規則な方向転換をするダミーを追い、連続命中を伸ばします。 |
| Elimination Training | 耐久値175の移動ダミーを撃破します。既定のダメージは1発25で、撃破ボーナスは350点です。 |

追従ドリルのダミーはラウンド中に撃破されません。**追従精度**は、ダミーに射線が通る時間のうち、クロスヘア中心がダミーに合っていた時間の割合です。中心と外縁寄りの4点で露出を判定します。未射撃でも計測し、完全な遮蔽とポーズは集計から除外します。**最長連続命中**は、連続して当たった最初と最後の弾の間隔です。ミスまたは既定の射撃間隔の1.5倍を超える間隔で区切ります。

## 移動練習

| 操作 | 入力 |
| --- | --- |
| 前後左右 | WASD |
| ジャンプ | Space |
| スプリント | Shift を押しながら移動 |
| しゃがみ | Ctrl または C を押し続ける |
| スライド | 地上で十分に加速したスプリント中に Ctrl または C を押す |

スライドはしゃがみキーを離す、ジャンプする、地面を離れる、終了速度まで減速する、上限時間に達する、のいずれかで終了します。スライド摩擦に加え、地面の傾斜に沿った重力成分を速度に反映します。左手の低い梁の下では立ち上がりが制限され、右手のスロープを上ると足場に登れます。

「設定 → 移動設定」で歩行・スプリント・しゃがみ速度、加減速、地上摩擦、空中加速度と制御率、ジャンプ初速、重力、スライド条件、視点高さの変化速度を調整できます。設定は `user://movement.json` に保存します。移動の既定値はこのアプリの練習用に調整した値です。

移動と衝突は120 Hzの物理更新で処理し、視点の位置を描画フレームに補間します。マウスの回転処理は固定視点と移動練習で共通です。 [Godot の CharacterBody3D](https://docs.godotengine.org/en/stable/classes/class_characterbody3d.html) · [Godot のカメラ補間](https://docs.godotengine.org/en/stable/tutorials/physics/interpolation/advanced_physics_interpolation.html)

## マウス感度

ホームとポーズ画面の両方で、基本感度・水平倍率・垂直倍率の上下ボタンは0.1ずつ変わります。小数の直接入力で細かく調整できます。

キャプチャ中は `InputEventMouseMotion.screen_relative` を使用します。この値はウィンドウのコンテンツ拡縮の影響を受けません。視点回転はイベントごとの移動量に感度を掛けて計算し、フレームのデルタ時間、補間、アプリ独自の加速は使用しません。練習中は `Input.use_accumulated_input` を無効化します。ピッチは ±89° に制限しています。 [Godot のマウス移動イベント](https://docs.godotengine.org/en/stable/classes/class_inputeventmousemotion.html) · [Godot の入力集約](https://docs.godotengine.org/en/stable/classes/class_input.html#class-input-property-use-accumulated-input)

Godot 4.7.2 の Windows バックエンドには、Windows Raw Input を登録して `WM_INPUT` などから処理する経路があります。登録に失敗した際はエンジンが経路を切り替えます。このアプリは Godot のイベントを使用し、デバイスごとの入力経路や USB ポーリング頻度を計測する機能は Phase 1 の範囲外です。 [Godot 4.7.2 の Windows 実装](https://raw.githubusercontent.com/godotengine/godot/4.7.2-stable/platform/windows/display_server_windows.cpp)

水平回転の係数は `基本感度 × プリセット係数 × 水平倍率` です。垂直も同じ式で垂直倍率を使います。`cm / 360° = 360 × 2.54 ÷ (DPI × 水平回転の係数)` で、入力した DPI から水平一回転の距離を表示します。DPI を変更するには、マウス本体またはメーカーの設定を使用してください。

| プリセット | 感度1.0での係数 |
| --- | ---: |
| 汎用 FPS | 1.0000° / カウント |
| VALORANT | 0.0694° / カウント |
| Apex Legends | 0.0218° / カウント |

ゲーム別プリセットには、マウス感度調整を扱った研究の係数を使っています。ゲームと同じ DPI を使用し、ゲーム側は腰だめ・加速なし・水平補正が既定値、アプリ側は水平倍率1.00を前提にしています。係数は近似値です。ここで合わせるのは物理的な水平回転量です。設定画面の FOV は垂直角で、ADS や画面上の移動距離は変換の対象外です。 [日本デジタルゲーム学会の発表予稿、式1](https://www.jstage.jst.go.jp/article/digrajprocsummer/2021/0/2021_27/_pdf)

## 計測と保存

- 左ボタンを押した時点のカメラ位置と照準方向を保持し、次の物理更新でヒットスキャンを実行します。最初に当たった衝突形状が現在のターゲットなら命中です。球体は使い回し、命中ごとにスタート地点から定義した範囲へ再配置します。
- スコアは命中数 × 命中点（既定100点）＋ 撃破数 × 撃破ボーナス（移動ダミー撃破で既定250点）です。命中率は命中数 ÷ 射撃数 × 100で、未射撃時は0.0%を表示します。連射間隔や再出現待ちで発射されなかった入力は射撃数に含めません。
- 反応時間は出現位置を表示するフレームの更新処理から、最初の命中弾の射撃時刻までを計測します。撃破時間は出現から最後の命中弾の射撃時刻までです。計測対象がゼロの場合は「—」を表示します。タイマーと両方の計測でポーズ時間を除外します。画面に光が出るまでの遅延や、マウスの機械的な入力遅延は計測値に含めていません。
- 感度設定は `user://settings.json`、自己ベストは `user://best_scores.json` に保存します。Windows の既定の保存先は `%APPDATA%\Godot\app_userdata\FPS Aim Training Studio` です。自己ベストはモードと練習条件別に記録し、移動練習では移動設定も区別します。 [Godot のデータパス](https://docs.godotengine.org/en/stable/tutorials/io/data_paths.html)

| `scripts/movement/` | プレイヤーの物理移動、姿勢、移動設定 |

| `scripts/scoring/` | 単調時計ベースの練習タイマー、スコア集計 |

シナリオ JSON は練習実行コードと独立しています。固定視点と移動練習は同じ静止ターゲットのセッションを使用し、シナリオの `player.movement_enabled` で移動体の有無を切り替えます。移動練習の障害物は `map.obstacles` に定義しています。
